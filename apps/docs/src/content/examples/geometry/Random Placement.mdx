This example explores several simple ways to procedurally position objects in your scene.

## Basic random

The simplest starting point is using [Math.random](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random) as is. Every object will be independently placed. Starting with a plane, a couple of Svelte's `{#each ... as ...}` blocks, and some random numbers, you can position objects like in the simple scene below.

## Object overlap

There is a limitation in using _just_ `Math.random`: it does not prevent objects from overlapping. This means that sometimes you'll see things like a tree growing from a rock.

One way to address this is with the [Poisson disk sampling](https://medium.com/@hemalatha.psna/implementation-of-poisson-disc-sampling-in-javascript-17665e406ce1) algorithm. It guarantees a minimum distance between two points which we'll use as object positions.

<Example path="geometry/random-placement/poisson-random" />

<Tip type="info">
  Notice If you reduce the minimum distance to smaller than your objects size then there will still
  be visual overlap.
</Tip>
